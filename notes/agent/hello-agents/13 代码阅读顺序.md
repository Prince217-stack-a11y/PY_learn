# 13 代码阅读顺序

> **用途**：教材 16 章配套代码共 **2500+ 个文件**，直接乱读会迷路。本清单给出**每章该读哪些文件、按什么顺序读、读的时候盯什么**。
> **约定**：
> - ⭐ = 核心，必读并动手改
> - 🔧 = 工程脚手架，扫一眼即可（配置/依赖/入口）
> - 📄 = 文档，读它比读代码快
> - 路径均相对 `hello-agents/code/`
> **配套读法**：第 N 章代码 ↔ 本笔记第 N 篇（见 README 对照表）。

---

## 总览：一条主线

```
ch1  Agent Loop 最小实现            ← 一切的原点
  ↓
ch2  ELIZA（规则驱动）              ← 理解"没有 LLM 的时代"
  ↓
ch3  N-gram → 词向量 → Transformer → BPE → Qwen   ← LLM 的底座
  ↓
ch4  ReAct / Plan-and-Solve / Reflection          ← 三种范式，必须重写
  ↓
ch5  低代码平台 JSON/YML 导出        ← 不写代码，看编排
ch6  四大框架 Demo                    ← 感受"规范"
  ↓
ch7  HelloAgents 框架（自建）          ← 全书最核心的工程代码
  ↓
ch8  记忆 + RAG                       ← 让 Agent 有记忆、有知识
  ↓
ch9  上下文工程                        ← 让 Agent 不"走神"
  ↓
ch10 MCP / A2A / ANP                  ← 让 Agent 接工具、能协作
  ↓
ch11 SFT + GRPO 训练                   ← 让模型变强
  ↓
ch12 BFCL / GAIA / 数据生成评估         ← 知道自己多强
  ↓
ch13-15 三个完整项目                    ← 看"整车"怎么装
  ↓
ch16 毕业设计规范                       ← 交付
```

| 顺序 | 文件 | 标记 | 读的时候盯什么 |
