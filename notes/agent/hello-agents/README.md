## 四、一页速览：全书主干

```
① 基础   智能体 = 在循环中自主调用工具的 LLM
         Agent Loop：感知 → 思考(规划+选工具) → 行动 → 观察 → ...
         LLM 是无状态的、会幻觉 → 需要记忆 + 工具 + 检索

② 范式   ReAct(边想边做) / Plan-and-Solve(先谋后动) / Reflection(事后复盘)
         工具三要素：名称、描述(最关键)、执行逻辑

③ 框架   低代码平台(Coze/Dify/FastGPT/n8n) → 主流框架(AutoGen/AgentScope/CAMEL/LangGraph)
         → 自建 HelloAgents：除 Agent 外，一切皆为 Tools（core / agents / tools 三层）

④ 增强   记忆(工作/情景/语义/感知) + RAG(转MD→分块→向量化→MQE/HyDE)
         上下文工程(上下文腐蚀、JIT、ContextBuilder、NoteTool、TerminalTool)
         协议(MCP连工具/A2A协作/ANP发现) + 训练(SFT→GRPO) + 评估(BFCL/GAIA)

⑤ 实战   旅行助手 / 深度研究 / 赛博小镇 / 毕业设计 → 33 条可复用工程模式
```
